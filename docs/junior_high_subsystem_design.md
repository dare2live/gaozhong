# 初中 + 中考 子系统顶层设计 (architect-controller, 2026-06-17)

> 用户立项: 拉沈阳中考英语真题 + 初中教材 + 课标, 像高中项目一样标注 vocab/grammar/考点;
> 核心洞察: "本项目里 with/the 之类明显不是高中词, 处理不便; **标注 stage 后就方便**"。
> 愿景: 本项目 → **初中+高中 统一教学/学习平台**。本次搭框架 + 标注, **将来打通**(非本次合并)。
>
> 本文是 **顶层设计 (legislator → controller → delegation)**, 非实现。实现按 §7 分期执行, 每期过 grill gate。

---

## 0. 定义权 (谁定义"对")

用户定义了 what-counts-as-correct 的内核: **stage 标注是第一性需求**(不是顺带), 因为它是
"初中 vs 高中 知识点边界"的可执行判定 — 没有它, "高中新词"无法和"初中已学词(with/the)"分开,
整个平台的分层教学就无依据。本设计据此把 **stage 维度立为创世级原语**, 不是事后加的列。

---

## 1. Genesis 层 (创世, 不可变, ≤3 条)

**why exist**: 给"初中→高中"知识点提供**单一、可执行、带阶段(stage)的真相源**, 使任一词/语法/考点
都能回答"在哪个学段首次引入、到某学段是否已学", 支撑分层教学 + 跨学段进度追踪。

**死亡线 (death lines, 跨者可判)**:
1. **stage 必有第一手课标背书** — 任一词/语法的 stage ∈ {小学,初中,高中必修,高中选必} 必须能溯回
   义务教育课标2022(一/二/三级) 或 高中课标2017(义教/必修/选必) 的**附录原文**; 推断/估算的 stage = 违反。
2. **学段锚定不混** — 中考分析只对**沈阳/辽宁实际卷型**(类比高中§7 辽宁卷锚定), 初中教材只对
   **沈阳实际选用版本**(§1.4 ≥2源核实后才锚定); 拿别地区/别版本冒充 = 违反。
3. **不破坏已清的高中地基** — 本次为独立并行构建(§6 DuckDB 独立); 不改高中现有 DB/schema/门禁,
   "打通"是将来按设计 UNION, 非本次混库。

**死亡条款 (何为失败)**:
- 感知死: stage 标注与课标原文不再对账(课标改版未重抽)。
- 判断死: 初中/高中边界靠人记而非课标数据化判定。
- 谄媚死: 为"覆盖好看"把没核实的版本/真题硬填(犯 gaokao 卷型坑)。

## 2. 核心原语: STAGE 维度 (用户洞察的工程化)

### 2.1 真相源 (两部课标拼出连续学段轴)
| stage | 真相源 | 附录位置 | 例 |
|---|---|---|---|
| 小学 (一/二级) | 义务教育课标2022 词汇表 一级/二级 | PDF p94-152 | with, the, book |
| 初中 (三级) | 义务教育课标2022 词汇表 三级 + 语法项目 | p94-152 / p116,p145 | environment, present perfect |
| 高中必修 | 高中课标2017 附录2 必修(*) | (已抽 cefr_vocab) | — |
| 高中选必 | 高中课标2017 附录2 选必(**) | (已抽) | — |

> 高中课标的 "义教"级(1580词) ≡ 义务教育课标的 一/二/三级 — **重叠是对账点**:
> 同一词两部课标都列 → 取**最早 stage** 为 `first_introduced_stage`(它是 canonical 标注)。
> 对不上的(高中义教有但义务课标无, 或反之) = 数据缺陷, 标 needs_review 不硬填。

### 2.2 标注语义 (让 with/the 问题可执行)
每个 word / grammar 节点加 **`first_introduced_stage`**(首次引入学段) + **`cumulative_through`**(到该学段是否已属可用集)。
则:
- **高中"新词"** = high-school-text-token ∩ word, **且** `first_introduced_stage ∈ {高中必修,高中选必}` —
  自动排除 with/the(小学)、environment(初中)。**这就是用户要的"处理方便"**。
- **初中教学** = `first_introduced_stage ∈ {小学,初中}` 的累积集。
- **跨学段进度**: 一词初中引入、高中复现 → edge `reinforced_in` 跨 stage 追踪(将来打通后)。

### 2.3 与现有"超纲/停用词"的关系 (复用本次成果)
- 本次已修: stopwords.yaml(with/the/has 不建 tests_word 边); cefr_vocab 义教/必修/选必 分级。
- stage 是其**上位泛化**: 把"义教"细分成 小学(一/二级)/初中(三级), 并接上中考侧。
- 迁移: cefr_vocab.cefr_level(义教/必修/选必) → 映射 stage; 义务课标三级补充"初中" stage 真相。

## 3. 架构 (separate-build, schema-compatible, merge-later)

> 张力: 愿景是"统一平台"(想共schema) vs §6 铁律"DuckDB独立"+ 不碰已清高中地基。
> 解: **本次并行独立构建 junior_high, schema 与高中同构 + stage 列**, 使将来打通 = UNION 非重构。

- **DB**: `data/db/junior_high.duckdb`(独立, 不 ATTACH 高中库; 类比 gaokao 独立)。
- **schema**: 复用高中 canonical 模型(nodes/edges + word/grammar/unit/section/exam_question),
  **每张表加 `stage` 列**(本次初中=小学/初中; 高中库将来加同列回填)。打通 = `UNION ALL` + 按
  canonical word/grammar 去重(同词跨 stage 保最早)。
- **代码**: `backend/services/junior_high/` 子包 + 复用高中 extraction/services 的**可复用部分**
  (vocab_renjiao/vocab/grammar 抽取器已是单一区段/单元锚定, 初中教材排版近似, 大概率可参数化复用)。
- **铁律继承**: 单一计算点 / Canonical First / Edges 一等公民 / D0 100% / 判断规则数据化(YAML)。

## 9. 研究核验结果 (Workflow wq9lacnsp, 2026-06-17, §1.4 ≥2源)

> 18 facts 多数 HIGH(≥2源/本地官方PDF直读)。**最贵的发现提前拦住了 gaokao 同类坑**。

### 9.1 🚨 致命修正: 沈阳初中 = 沪教牛津版 (本地缺, ≠高中)
- **沈阳初中英语 = 沪教牛津版(上海教育出版社, "广州深圳沈阳通用"分支), NOT 人教 NOT 外研** (4源: textbook-info + 知乎 + 学科网, HIGH)。
- 辽宁14市初中**三分**(非高中二分): 沈阳=沪教牛津(1市) / 大连·营口=外研(2市) / 其余~11市=人教。
- **本地 data/junior_high/textbooks/ 只有 renjiao+waiyan(扉页确认=人教Go for it!+外研新标准), 沪教牛津 0 命中 → 沈阳本市主用版缺失**。
- ⚠️ **这推翻了 §4 数据清单"待核沈阳是否用人教/外研"的隐含假设** — 同城初/高中版本不同, **绝不能复用高中§4二分推初中**(=gaokao 卷型坑)。死亡线#2 强化: 初中版本独立建表, 不继承高中。

### 9.2 中考 PIT: 命题主体 2024 断点 (比高中卷制切换更硬)
- ≤2023 沈阳**自主命题**(英语100分/100分钟, 旧题型) → ≥2024 辽宁**省统一命题**(辽教发〔2021〕49号, 外语120=笔试90+听力口语30, 删单选+综合阅读, 增五选四+开放题, **对接高考方向**)。
- 真题源全民间聚合(中考网主源 + book118/菁优网等), **无官方发布**(jyt.ln.gov.cn 473反爬, 只发样卷不发真题PDF — 同高中困境)。
- grill 结论: **2024+省统一卷拉了有用**(对接高考方向, 仅2年量小可手工质检入 review); **≤2023自主卷只能做分布快照不做趋势**(跨2024断点=坑12违规)。死亡线#2: 中考卷型必 PIT 分段(自主/省统一两 era), provenance 分层 + smoking-gun + 禁押题(§3.2)。

### 9.3 义务教育课标2022 可抽取性 (S级本地直读, 比高中侧更强)
- 词汇表 附录3(PDF idx93): **三级1600词**(含505二级带*=小学 + 1095初中, 各地可增100~300)。
- 语法项目表 附录4(idx144-148): 词类/构词法/句法, "+"标=仅理解的三级项 → 可逐项标级。
- 三级体系(一级3-4年级/二级5-6年级/三级7-9年级) = **天然 stage 锚**, §2 stage 原语真相源坐实。
- ⚠️ 抽取护栏: 本地多栏抽得~1377 vs 官方1600 → 必写专门 parser **assert==1600**(含505带*), 不凑数(§1.3)。

### 9.4 顶层设计前必须用户拍板的决策 (load-bearing, directional)
**项目定位 = 服务沈阳本市 / 覆盖全辽宁?** — 决定沪教牛津是否 STEP1 硬阻塞:
- 服务沈阳 → **必先补沪教牛津7-9年级(当前0)**, 是 STEP1 gate 硬阻塞。
- 覆盖全辽宁 → 现有人教+外研覆盖13市, 沪教是沈阳本市缺口(仍需补但非全盘阻塞)。

### 9.5 verdict 修订
**PROCEED with HARD GATE**: 课标侧(义务教育2022 S级直读, 三级1600+语法可抽)可立即开 Phase1。
但**教材+中考侧阻塞于定位决策**: 用户未定"沈阳/全辽宁"前不锚定教材主用版、不拉沪教牛津、不拉中考。
stage 原语真相源(义务课标三级 + 高中义教/必修/选必)已 HIGH 核实, linchpin 稳。
