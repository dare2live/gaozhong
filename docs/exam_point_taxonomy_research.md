# 高考英语考点分类体系研究 — 官方依据 + 细粒度修订建议

> 日期：2026-06-15
> 用途：回答用户质疑——「当前 taxonomy（`backend/config/exam_point_taxonomy.yaml`）太粗犷、能细分么、考纲就是这么分类的吗」。
> 方法：**官方源（Truth/S 级）优先**，每个分类层级标明来源；找不到官方依据的**诚实标「民间归纳/约定」**，绝不把教辅分类冒充课标官方。
> 本文**只读研究 + 写本 md**，不改 taxonomy yaml、不改 DB、不 commit。
>
> **诚实红线贯穿全文（CLAUDE.md §1.3 + §3.2 + gaozhong-ops 坑12 分析诚实门）**：
> - 🟢 = 官方文件原文有明确分类层级（可逐字溯源）。
> - 🟡 = 官方有「上位概念」但**没有把它拆成考点小类**，小类是命题/教辅/本项目的**实证归纳**。
> - 🔴 = 纯民间教辅约定，无官方依据。

---

## 0. 一句话结论（先给用户）

1. **主题语境（theme）的「粗」不是分类体系粗，而是项目只用了 L1（3 大主题语境）**。课标官方本身就是**三级**结构：**3 大主题语境 → 10 主题群 → 32 子主题内容**。本地 `theme_contexts.jsonl` 已经把这三级抽出来了（L1/L2 与官方**完全一致**），taxonomy.yaml 却只引用了 L1。**细分的官方料一直在仓里，没用上**。
2. **设问类型（主旨/细节/推理/词义/态度）确有官方依据，但比项目用的 5 类更细**：教育部考试中心《中国高考评价体系》把阅读理解界定为 **7 项理解性技能**。项目的 5 类是这 7 项的**合并简化**，方向对、但不是官方原话，应**对齐官方 7 项**并标注映射。
3. **体裁（genre）有官方依据**：课标「语篇类型」是课程内容六要素之一，官方列举记叙文/说明文/议论文/应用文 + 连续性/非连续性文本。项目 6 类基本落在官方范围内，但**「书评介绍」「新闻报道」是命题实证细分，非课标顶层并列项**，应标注层级。

最关键的「细分」建议：**theme 直接升到课标三级（用现成 `theme_contexts.jsonl`）；question_intent 对齐官方 7 项理解性技能；genre 分「课标官方 L1 文体」与「命题实证 L2 子类」两层**。

## 1. 维度一：主题语境（theme）—— 课标官方三级层级 🟢

### 1.1 官方依据

**来源（S 级，Truth）**：教育部《普通高中英语课程标准（2017年版2020年修订）》「课程内容」之「主题语境」。
- 官方 PDF（本仓）：`data/curriculum/national/普通高中课程方案及20科课程标准（2017年版2020年修订)/4.普通高中英语课程标准（2017年版2020年修订）.pdf`
- 官方在线（教育部课程教材研究所 ictr.edu.cn 官方托管）：<https://www.ictr.edu.cn/Uploads/File/2025/02/07/4.普通高中英语课程标准（2017年版2020年修订）.pdf>
- 教育部印发通知：<http://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html>

### 1.2 官方三级层级（完整列出）

课标把「主题语境」组织为**三级**（官方表述：主题语境 → 主题群 → 子主题内容）：

| L1 大主题语境（3） | L2 主题群（官方共 10 个） | L3 子主题内容（官方共 32 项） |
|---|---|---|
| **人与自我** | 生活与学习 / 做人与做事（**2 群**） | **9 项**（个人家庭生活、健康生活方式、自我认识与完善、终身学习、语言学习规律与方法、优秀品行与社会责任、生命意义、职业发展规划、创新创业意识） |
| **人与社会** | 社会服务与人际沟通 / 文学、艺术与体育 / 历史、社会与文化 / 科学与技术（**4 群**） | **16 项**（人际关系、公益志愿、跨文化沟通、文学作品、绘画建筑等代表作、影视音乐、体育赛事、民族文化习俗、杰出人物、国际组织、法律常识、文化遗产、社会热点、历史事件、人类文明进步、科技创新） |
| **人与自然** | 自然生态 / 环境保护 / 灾害防范 / 宇宙探索（**4 群**） | **7 项**（地理概况、自然遗产保护、人与环境关系、自然灾害防范、人类生存社会发展与环境关系、科学研究成果、宇宙探索） |

> 即官方 **3 → 10 → 32** 三级结构。来源已 ≥2 独立源印证（课标 PDF 原文 + ictr 官方托管 PDF + 比利闪记课标镜像 dancisuji.cn/yingyukebiao/320）。

### 1.3 本地资产 vs 官方层级 对照

本仓 `data/structured/curriculum/theme_contexts.jsonl`（48 条）实测结构：

| 层级 | 本地条数 | 官方条数 | 一致性 |
|---|---|---|---|
| L1 大主题语境 | 3（人与自我/人与社会/人与自然） | 3 | ✅ **完全一致** |
| L2 主题群 | 10（命名逐字一致：生活与学习…宇宙探索） | 10 | ✅ **完全一致** |
| L3 子主题 | 35（人与自我10 / 人与社会16 / 人与自然9） | 32（9/16/7） | 🟡 **L2 完全对齐；L3 是项目对课标子主题内容的再归纳，命名更「话题化」、条数略多（35 vs 32），非课标逐字 32 项** |

> **诚实结论**：theme 的 **L1+L2 是 100% 课标官方**（3 大主题 + 10 主题群，命名一字不差）；**L3 是项目派生**（贴近课标但非逐字 32 项内容）。当前 taxonomy.yaml 只取了 L1 的 3 个 label——**这才是「粗」的根因，不是课标粗，是没引用已抽好的 L2/L3**。

## 3. 维度三：设问类型（阅读理解考查能力）🟢 官方框架 + 🟡 项目 5 类简化

> **这是用户最该关注的「有没有官方依据」的维度——答案：有，而且比项目用的更细。**

### 3.1 官方依据：阅读理解 = 7 项理解性技能

**来源（S 级，教育部考试中心，≥3 独立源印证）**：
- 教育部官网：<http://www.moe.gov.cn/jyb_xwfb/s5147/202007/t20200709_470940.html>
- 陈康等《基于高考评价体系的英语科考试内容改革实施路径》（中国教育考试网 chsi.com.cn / 教育部考试中心）：<https://gaokao.chsi.com.cn/gkxx/stpx/stjd/202107/20210719/2192143441.html>
- 教育部考试中心《2021 高考英语全国卷试题评析》：<https://gaokao.chsi.com.cn/gkxx/stpx/stfx/202112/20211230/2192143439.html>

**官方原文**：英语科关键能力（语言能力）= **4 种**，分两类：
- **理解性技能**：听力理解、阅读理解
- **表达性/产出性技能**：书面表达、口语表达

其中**阅读理解归纳为 7 项具体能力**（官方逐字）：
> 1）理解词汇　2）理解具体信息　3）理解主旨要义　4）理解观点、态度　5）理解目的　6）推断　7）理解文章结构、类型

并且官方对命题趋势有明确表述：**「考查理解具体信息能力的试题量在减少，考查推测、联想、提炼和批判等思辨能力的试题量在增加」**（教育部考试中心评析）——这直接支撑项目的「考点趋势分析」核心竞争力，且是**官方背书的迁移方向**。

### 3.2 项目现用 5 类 vs 官方 7 项 映射

当前 taxonomy.yaml `question_intent` 用 5 类，是官方 7 项的**合并简化**：

| 项目现用（5 类，🟡 实证归纳/教辅常用名） | 对应官方 7 项理解性技能（🟢 教育部考试中心） | 关系 |
|---|---|---|
| 主旨大意 | ③ 理解主旨要义 + ⑦ 理解文章结构、类型 | **合并**（项目把「主旨」「标题」「结构」并成一类） |
| 细节理解 | ② 理解具体信息 | 1:1 |
| 推理判断 | ⑥ 推断 + ⑤ 理解目的（部分） | **合并** |
| 词义猜测 | ① 理解词汇 | 1:1 |
| 态度观点 | ④ 理解观点、态度 | 1:1 |
| （无） | ⑤ 理解目的 | **缺失**（写作目的/作者意图未单列） |
| （无） | ⑦ 理解文章结构、类型 | **缺失**（被并进主旨） |

> **诚实结论**：项目 5 类的**命名是教辅/命题通用约定**（🟡，「主旨/细节/推理/词义/态度」是民间高频说法），但**底层概念都能映射到官方 7 项**（🟢）。`exam_scenario_patterns.md §1.3` 已实证：辽宁卷设问以**细节理解主导（~2/3）**+ 词义/主旨/态度/推理少量，两卷制段一致——这是项目自己的实证，**不是官方占比**。
> **修订方向**：把官方 7 项作为 **L1 受控全集**（标 🟢 教育部考试中心），项目 5 类降为 **L2 工作分类 / 别名**（标 🟡），并补回缺失的「理解目的」「理解文章结构类型」，避免漏掉官方明列且趋势上升的能力项。

### 3.3 顺带：书面表达官方 4 维度（taxonomy 未覆盖，建议补）🟢

教育部考试中心同文给出**书面表达 4 维度官方要求**（可用于应用文写作/读后续写评分维度）：
> 1）内容完整、清楚、合理、逻辑性强、符合写作目的与情境；2）词汇和语法结构多样且准确恰当；3）整体结构清晰、句间段间衔接有效、意义连贯；4）单词拼写正确、标点大小写规范。

> 这是产出性技能的官方考点维度，当前 taxonomy 完全没有写作维度——若未来标注续写/应用文考点，应以此 4 维度为官方骨架。

## 4. 维度四：语法考点（grammar_point）🟢 官方全集 + 🟡 高频面归纳

### 4.1 官方依据：课标语法 106 项三级体系

**来源（S 级）**：课标附录「语法项目表」，已抽入本仓 `data/structured/curriculum/grammar_items.jsonl`（106 项，逐字溯源课标 PDF）。

官方三级结构（DB 实测）：

| L1 大类（3） | L2 类（28） | L3+ 细目 |
|---|---|---|
| **一 词类** | 名词/动词/形容词/副词/代词/数词/介词/连词/冠词/感叹词（10） | 71 项 L3 + 4 项 L4 |
| **二 构词法** | 合成法/派生法/转化法/缩写和简写（4） | |
| **三 句法** | 句子种类/句子成分（按结构·按功能）/基本句型/**谓语动词的时态**/**被动语态**/**动词的非谓语形式**/主谓一致/并列复合句/**主从复合句**/省略/倒装/强调/**虚拟语气**（14） | |

> CEFR 标注：90 项「义教」/ 4 项「必修」/ 8 项「选必」/ 4 项「选修」——可据此做 PIT「该单元已学语法」白名单（CLAUDE.md §1.2 不偏离学校）。

### 4.2 项目现用 9 类 vs 官方 句法体系 映射

taxonomy.yaml `grammar_point` 用 9 类，是**官方「三 句法」+ 部分词类的高考高频面归纳**：

| 项目现用（9 类，🟡 高考高频面） | 官方课标语法项（🟢） |
|---|---|
| 动词时态语态 | 三/谓语动词的时态 + 三/被动语态 + 三/主谓一致 |
| 非谓语动词 | 三/动词的非谓语形式 |
| 定语从句 | 三/主从复合句（定语从句） |
| 名词性从句 | 三/主从复合句（名词性从句） |
| 状语从句 | 三/主从复合句（状语从句） |
| 连词介词 | 一/介词 + 一/连词 + 三/并列复合句 |
| 冠词代词 | 一/冠词 + 一/代词 |
| 构词派生 | 二 构词法（派生法/转化法） |
| 形容词副词比较 | 一/形容词（比较级最高级）+ 一/副词（比较级最高级） |

> **诚实结论**：9 类**全部能映射到课标官方语法项**（🟢 底层），但**「9 类」这个粒度本身是高考语法填空/完形高频考查面的归纳（🟡）**，不是课标的分类切法（课标是按词类/构词/句法切，不按「考点」切）。`exam_scenario_patterns.md §4.2` 实证辽宁语法填空约 **7:3 偏向「给词变形」（时态/非谓语/派生）vs 纯空填功能词（冠/介/连/关系词）**——这是项目实证高频面，n=2 篇标样本不足，但与公认新高考语法填空考纲一致。
> **修订方向**：保留 9 类作 **L2 高频考点面**（标 🟡 高考实证），但在每个 label 加 `curriculum_ref` 指回 `grammar_items.jsonl` 的官方 L1/L2 项（🟢），实现「考点面 ↔ 课标语法」可溯源。

## 5. 维度五：体裁（genre）🟢 课标官方文体 + 🟡 命题实证子类

### 5.1 官方依据：语篇类型是课程内容六要素之一

**来源（S 级 + ≥2 独立源）**：
- 课标「课程内容」六要素 = 主题语境 / **语篇类型** / 语言知识 / 文化知识 / 语言技能 / 学习策略。
- 课标原文：「语篇类型是指**记叙文、议论文、说明文、应用文**等不同类型的文体，以及口头、书面等多模态形式的语篇」；并区分**连续性文本 / 非连续性文本**（图表、网页、广告、漫画等）。
- 镜像源：课标语篇类型内容要求 <https://www.dancisuji.cn/yingyukebiao/321.html>（比利闪记，B 级镜像；与课标 PDF 一致）。

课标**必修**列 7 类语篇（对话访谈/记叙文/说明文/应用文/新闻报道/新媒体语篇/其他），**选择性必修**扩展（专题讨论讲座/科幻幽默故事/议论文/深层说明文/正式应用文/博客等）。

### 5.2 项目现用 6 类 vs 课标官方 映射

| 项目现用（6 类） | 课标官方语篇类型（🟢/🟡） |
|---|---|
| 记叙文 | 🟢 课标顶层文体（必修明列） |
| 说明文 | 🟢 课标顶层文体（必修明列） |
| 议论文 | 🟢 课标顶层文体（必修/选必明列） |
| 应用文 | 🟢 课标顶层文体（必修明列；含书信/邮件/通知/告示） |
| 新闻报道 | 🟢 课标必修明列「新闻报道」 |
| 书评介绍 | 🟡 **命题实证子类**，非课标顶层并列项（属应用文/说明文下的具体语篇形式） |

> **诚实结论**：6 类里 **5 类（记叙/说明/议论/应用/新闻报道）是课标官方语篇类型**（🟢）；**「书评介绍」是项目对辽宁卷阅读 A 篇 listing/书画册介绍的实证细分**（🟡，`genre_theme_labels.jsonl` 中仅 4 例）。课标还有**连续性/非连续性文本**这一**正交维度**，项目当前完全没建（应用文 listing、图表题其实是非连续性文本）——可作为**第二正交维度**补充。
> `exam_scenario_patterns.md §1.1` 实证辽宁阅读**位置-体裁强绑定**：A=应用文/listing、B=记叙、C/D=说明/议论——这是项目可固化的结构规律（🟡 实证，非课标规定）。

## 6. 修订建议：分层细粒度 taxonomy（每维度 ≥2 级）

### 6.1 总原则

1. **每个 label 带 `provenance` 字段**：`official_curriculum`（🟢 课标）/ `official_neea`（🟢 教育部考试中心/评价体系）/ `empirical_liaoning`（🟡 188 真题实证）/ `convention`（🟡 教辅通用名）。**绝不让 🟡 冒充 🟢**（gaozhong-ops 坑1 绿门假绿、坑12 分析诚实门）。
2. **L1 用官方全集，L2 用细分/别名**：分类查询走 L1（可溯源官方），标注/展示走 L2（细粒度）。
3. **PIT 分段**：题型/分布按卷制 era（2015–2020 旧课标全国 II / 2021+ 新高考全国 II）分，不跨卷制混（gaozhong-ops 坑12 第2条）。
4. **样本量护栏**：辽宁新高考 II 段 140 题→**分布可信**；**逐年趋势不可信**（5 年、2023 仅 6 题）。设问/语法高频面 n=2~4 篇标「结构性观察，样本不足」。

### 6.3 现有 `genre_theme_labels.jsonl`（粗）→ 细粒度 迁移路径

现状：`data/structured/exam_point/genre_theme_labels.jsonl`（188 辽宁题，双模型标注）只标到 **genre（6 类）+ theme（L1 3 类）**，且有 `NA`/多值（如「说明文|新闻报道」需 needs_review）。

迁移建议（**不破坏单一计算点 Rule 1**，只加细粒度列，不重算）：
1. **theme L1 → L2/L3**：对每条已标 L1 的题，让双模型在该 L1 下**细分到 `theme_contexts.jsonl` 的 L2 主题群**（如「人与社会」→「科学与技术」）。L2 全集来自官方，可溯源；歧义标 `needs_review` 不入分布（沿用现有 dual_model_agree 门槛，gaozhong-ops 坑4 派生完整性）。
2. **genre 6 类 → L1 官方 + L2 子类**：把「书评介绍」「新闻报道」归到 L1 官方文体下，多值（「说明文|新闻报道」）走 `needs_review`，不进 canonical 分布。
3. **question_intent 落地**：对阅读理解小题，按官方 7 项标注（设问句 cue 匹配），provenance 分层（human/dual_model/llm，C 级 LLM 必双校验，taxonomy.yaml `provenance_levels` 已留位）。
4. **可溯源锁**：每个细粒度 label 在 yaml 加 `provenance` + `curriculum_ref`/`neea_ref`，并在 `moth` 加一条断言锁住「🟡 不冒充 🟢」（如 `question-intent-official-7`：question_intent L1 必含官方 7 项）。

## 7. 诚实声明与缺口（D0 要求）

1. **theme L3（32 子主题内容）未逐字入仓**：本地 `theme_contexts.jsonl` 的 L3（35 项）是项目对课标「子主题内容」的话题化再归纳，**非课标逐字 32 项**。若要 🟢 级 L3，应从课标 PDF「主题语境内容要求」表逐字补抽（待办）。
2. **设问类型项目 5 类是教辅约定**：底层映射官方 7 项可靠，但「主旨/细节/推理/词义/态度」这 5 个**名称**是民间通用名（🟡），不是课标/评价体系的原话分类名。已在 §3.2 标明，不冒充官方。
3. **辽宁实证占比 ≠ 官方规定**：设问以细节主导（~2/3）、语法 7:3 给词变形、体裁记叙↔说明翻转——都是**本项目对辽宁真题的实证**（🟡），样本量护栏见 `exam_scenario_patterns.md` §10。**不可表述为「考纲规定如此」**。
4. **七选五命名**：库中 `完形填空(七选五/语篇)` 是实现别名，官方名是**阅读理解第二节**，已在 §2.2 标明，避免误读为完形子类。
5. **卷型/分值**：分值结构来源为新高考分析合集（B 级）+ 教育部官网能力表述（S 级），分值已 ≥2 处印证；逐年具体分值微调以当年官方《考试说明》为准（辽宁不单独发考纲，随全国卷）。
