## 0. 为什么有这份文件 (定位重置 + 诚实复盘)

多轮迭代把项目磨成了"教研工具 + 数据正确性"(前端 RC1、两轮口径审计), 但**用户真正要的产品(第三层课程)一直没建, 且其内容早被回滚**(坑6)。症状: 截图里课程弹窗甩原始题号 `gb/...44`、关联只显孤词 "a"、正文为空 —— "后端算出来了, 前端完全看不出意思"。

**根因 = 两病叠加**: ① IA 是"备课工具"逻辑, 不是"学习产品"逻辑; ② L3 课程内容不存在(回滚)。修前端修不出产品 —— **必须把产品三层补齐, 以 L3 为心脏**。

### 用户 2026-06-27 拍板
- **A. 教师工具下线** (备课/学情/组卷/扫描). 但**课程设计必须含作业**: 流程 = 教学提纲 → 每节备课内容/课程/作业 → 保证整体与每节匹配。
- **B. 高中先跑通** (数据最全的样板), 初中同结构镜像放第二步。
- **C. 建 L3 框架, 内容先不生成** —— L3 内容依赖 L1/L2 数据正确, 先搭框架, 数据达就绪门再填内容。

### 消费者锚定 (mio #10)
**主消费者 = 学习者(学生)**, 产品是"用最少课程吃透高考/中考考点 + 命题套路"的学习产品。教师端日后若做, 单独开"教师模式", 不混入主线。

## 2. 产品信息架构 (IA) — 高中板块(初中镜像)

入口: **初中 | 高中** 两大板块. 每板块四页:

1. **① 命题研判 首页** —— 打开即"**先结论后证据**": 一句话讲清"高考英语考什么、怎么考、近年怎么变"(L2 趋势自动生成的研判结论), 图表/热力作佐证。重构现"考点驾驶舱"(它有图无结论=看不懂)。
2. **② 真题特点** —— 围绕真题的统计/热力: 题材·主题·设问思维分布与迁移、**小学/初中/高中单词在高考卷的占比**(王牌实证, 见 §4)、考查方式套路。
3. **③ 基础库** —— 教材库 / 真题库 / 课标库, 可查可溯源(每条能回溯原始 PDF/题目)。
4. **④ 40 节课程(L3 心脏)** —— 教学提纲 → 每节(备课内容/课程正文/作业)→ 每段/每考点↔命题趋势高度对应(见 §3)。

下线: 现"备课/分层教学/讲课/单元备课/学情/题库组卷/扫描"诸 tab(教师逻辑)。研判/驾驶舱/知识图谱/词典/教材 → 重构并入①②③。

## 3. L3 框架设计 (本次只搭框架, 不生成内容)

### 3.1 自上而下的设计流 (用户拍板的顺序)
1. **教学提纲 (syllabus)** —— **不是手写, 是 L2 派生**: 从考点全集(§4)按"最少覆盖最大 + 命题权重"算出"教哪些考点、什么顺序、切成 N 节", 每节定一个**考点焦点集**。先出提纲框架(考点→课节映射), 零内容。
2. **每节 = 备课内容 + 课程正文 + 作业**, 三者同节设计、口径一致:
   - **备课内容**: 本节考点焦点 + 对应真题 + 命题套路(该考点怎么考)。
   - **课程正文(可背诵 2-3 段)**: **本次不生成**(待就绪门)。框架先占位 + 定生成契约(§6)。
   - **作业**: **= 真题(从题库选), 非生成**(坑14 不押题)。框架现在就能挂: 本节考点 → 命中该考点的真题作业。
3. **整体↔每节匹配 (coherence)**: 全 40 节的考点焦点并集 = 覆盖目标集; 无重复浪费、无遗漏高频考点(由 §4 覆盖证明守)。

### 3.2 段级可溯源 schema (替掉"甩原始题号")
L3 的每个内容单元(段)是**可溯源对象**:
```
course_segment: { segment_id, course_id, seq,
  covers_exam_points: [exam_point:cognitive_skill:推断, exam_point:genre:记叙文, word:X, grammar:Y],
  evidence_questions: [真题id...],          # 该段练的考点来自哪些真题
  trend_weight: 该考点在命题趋势里的权重,   # 让"高度对应"可量化
  content: null(待就绪门生成) }
```
前端点任一段/句 → 弹"这段练『推断题』(高考占47%) + 这些词 + 这3道真题", **取代现在的 `gb/...44`**。
**D0 门**: 每 segment 必有 ≥1 covers_exam_point 且该考点存在于 L2(无孤儿内容); 作业题必命中本节考点。

## 4. 覆盖模型 (深度盲点 #1 — "最少覆盖最大"必须可证明)

用户说"40 节覆盖所有考点"——但**不定义考点全集 + 覆盖度量, 这句话不可验证**。本节把它做成可算可证:

- **考点全集 (universe)** = L2 派生, 四轴: 题材(genre) · 主题(theme_l2) · 设问思维(cognitive_skill) · **高频考点词/语法**(离散考查集, 按命题频次加权)。
- **覆盖定义**: 一节课"覆盖"某考点 = 其课程焦点 + 作业真题 教/考了它。
- **最少覆盖最大 = 加权集合覆盖**: 选最少课节, 覆盖**按命题权重排序**的考点, 目标 = 覆盖占考试权重 ≥ X% 的考点集(见盲点 §7: **不是字面 100%**, 低频长尾考点性价比低)。
- **覆盖证明**: 每节 + 累计**覆盖率%** + **缺口报告**(哪些高频考点未覆盖)。这是产品对外的硬底气("这40节覆盖了高考 X% 考查权重")。
- **D0 门**: 覆盖率 + 缺口可复现; 缺口=0 高频考点(或显式列出待补)。

## 5. L3 就绪门 (把用户"等数据正确"操作化)

C 决策"内容依赖 L1/L2 正确"= 需一道**明确的就绪门**判"地基够不够填 L3 内容"。绿才允许生成:

- [ ] **教材提取完整**: 高中外研+人教 单元/词表/课文 100%(初中板块另算)。
- [ ] **考点标注可信**: 题材/主题=双模型一致 **且对第一手教研解析交叉验证**(坑16); 设问思维=explicit_label 真值。
- [ ] **关联口径正确**: 出现≠考查(tests_word 离散口径) / 篇章级 genre-theme / 卷制分段 —— 本季已修(见 RESUME 根因A/B), 三门绿。
- [ ] **覆盖模型跑通**: 考点全集 + 覆盖率可算(§4)。
- [ ] **小初高词占比验证**(§4 王牌实证可信)。

就绪门绿 → 才进 Phase D(L3 内容生成)。**现在: 大部分已绿, 教材初中 + 覆盖模型 是主要待办** → 故本次先搭 L3 框架 + 把就绪门补齐, 不生成内容。

## 6. L3 内容生成诚实护栏 (生成前必为门, 防回滚重演)

L3 正文一旦生成(Phase D), 必受这些**硬门**约束(回滚就是因为当年无门):
- **词量**: 每段英文词 ⊆ 该阶段已学单元 ∪ 课标 3500(高中)/对应初中课标。越纲即拒。
- **语法**: 只用已学/已覆盖的语法考点。
- **不抄教材**: 10-gram 不与教材原文重叠(自己语言重述)。
- **exam-grounded**: 套路/重点直接来自 L2 真题解析, 非臆造; 非押题(题面/答案不预测)。
- **自证覆盖**: 每段能反证"覆盖了哪些考点 + 对应哪些真题"(§3.2 schema)。
- 生成走 review gate 入库(C 级 LLM 产物必双校验, §3.2 来源分层)。

## 7. 深度 / 广度扩展 + 盲点 (mio 主动分析师 — 超出"满足需求")

### 深度
- **套路 = 一等可教对象**: 不止"考什么"(词/语法/题材), 更教"怎么考"(设问思维×题材, 如"记叙文常考推断")。课程显式教套路("遇记叙文先想推断"), 这是用户说的"命题方式"的落地。
- **高产出优先 (小初高词占比的真用途)**: 若高考卷 70% 词是初中/小学级, 高中课程**不重教低产出词**, 只攻"高频考 × 高中新增"的 delta —— 这才是"最少覆盖最大"的真算法, 不是平均背 3500。
- **可溯源即 D0**: L3 每段↔L2考点↔L1真题 全程可点可验, 无孤儿内容(§3.2 门)。

### 广度
- **初中→高中衔接是产品价值, 不是两个孤岛**: 用 deepens 边展示"你初中学的→高考怎么深化", 学习者看到连续性(K12 轴)。
- **学习者侧缺口闭环(轻, 非教师学情)**: 学习者做摸底 → 看自己**还缺哪些考点** → 课程高亮那些。这是面向学生的个性化, 与下线的教师"学情"不同。
- **重定位/命名**: "沈阳/辽宁高中英语教学系统"(教师系统口吻)→ 学习者产品(初中+高中)。择期重命名。

### 盲点 (诚实提示, 防 over-claim / over-engineer)
- **"覆盖所有考点"不可字面成立也不该**: 长尾低频考点性价比低; 诚实目标 = **覆盖占考试权重 ≥X% 的高频考点**(§4 加权), 不是 100% 全覆盖。否则违 mio 目标量诚实。
- **"每句话对应趋势"易过度**: 主口径落**段级**(每段一个考点焦点), 句级为可选下钻, 别给每句强标(奥卡姆)。
- **L1/L2 正确 ≠ L3 内容自动有用**: 就绪门(§5)守地基, 但 L3 内容质量需 review gate + 学习者真实反馈验证(目标量), 别把"数据绿"当"课程有效"(坑12 升级版)。
- **教师工具下线 ≠ 删数据**: 学情/组卷的**底层数据/服务**(真题池/弱点派生)L3 作业、摸底仍要复用; 下线的是教师向 **tab/UI**, 不是后端能力。
