## 0. 立法层 — 什么算"好的闭环" (5 角色收敛后重写 vision)

用户原话"充分发挥交互、任一节点看一切"经实测**收敛重写**:
- **不是** "多连几条边 / 更可点" (browse-for-browse, 漂亮但无人用)。
- **是**: 图谱获得它**缺失的第二轴(怎么考/命题方式)**, 从现有真相源**诚实建模**, 每个 facet 带 **provenance + 样本量**, 锚定**消费者决策**。
- **闭环 = 手段, 不是目的**。目的 = 让老师在下一节课/下一份卷做一个**不同的决策**。
- **护城河 ≠ 前端交互**, = 诚实的、带 provenance 的、**双轴(考什么 × 怎么考)证据底座** — LLM 聊天机器人造不出来。

## 2. 超越 — 跳出"可点击"的 10x 方向 (发散)

- **命题方式作边 metadata + method 节点双形态**: `tests_via_method` 边的 evidence 携带"怎么考"载荷(锚点线索/同义替换关系/干扰项类型); `method` 节点(设问类型/解题路径)作可导航 center。
- **图谱当组合查询面, 非单节点 browse**: "新高考 era ∩ 人与自然 ∩ 推理判断 → 命中题集" — 三轴交集查询才是"大数据整合", 1-hop browse 不是交互天花板。
- **证据闭环作全局铁律**: 每个图上 claim(占比/趋势/命题方式标签)在 UI 一键溯源到**原题 + 解析 + provenance 徽章**。这才是护城河。
- **诊断闭环(学生)**: 错题 → 该题命题方式标注 → 聚合"此生推理判断类弱" → 按同 method 生成**同构练习(结构对齐造题, 非押题)**。
- **干扰项设计轴(富矿)**: 教研解析常解释错项为何错(偷换概念/过度推断/无中生有/正话反说) — 这是"解题思路"真相源, 现有源可提, 比"同义替换"单点价值更高。
